Formula and methodology

Weighted score: contribution 25%, commitment 25%, capital 20%, role 20%, idea/IP 10%; each allocation is its share of total score.

The calculator applies this stated method directly to the values you enter. Keep amounts and time periods consistent.

Worked example

Equal scores produce a 50% / 50% split. Different inputs shift the allocation transparently.

How to use

  1. Enter the requested values using consistent units and periods.
  2. Select Calculate.
  3. Review the result, method and limitations before using it in a decision.
