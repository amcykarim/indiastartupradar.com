# IndiaStartupRadar

IndiaStartupRadar is a lightweight static tools platform for Indian startups, businesses, freelancers, marketers and ecommerce sellers.

## Architecture

- `tools/` contains functional tool pages.
- `categories/` contains curated category landing pages.
- `guides/` contains future supporting guides.
- `assets/css/site.css` is the shared design system.
- `assets/js/site.js` contains shared progressive enhancement.
- `assets/js/tools/` contains isolated tool logic.

The site requires no build step and is compatible with direct GitHub Pages publishing. Tool calculations should remain client-side whenever practical. New tools must include useful functionality, methodology, examples, accessibility, validation, SEO metadata and appropriate disclaimers.
